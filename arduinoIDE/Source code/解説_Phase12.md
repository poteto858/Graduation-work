## 2. アーキテクチャの全体像（最重要）

```
┌─────────────┐   HTTPリクエスト    ┌──────────────────────────┐
│  ブラウザ    │ ───────────────▶  │ Arduino UNO R4 WiFi        │
│ (ゲーム本体) │                    │  - Webサーバー             │
│  JavaScript │ ◀───────────────  │  - HTMLを丸ごと配信         │
└─────────────┘   HTMLや/state返答  │  - /state でジョイ値をJSON  │
                                    └──────────────────────────┘
```

- **ゲームのロジックは全部ブラウザ側の JavaScript**。Arduino は「HTMLを配る」「ジョイスティックの値を返す」だけ。
- だからジョイスティックが無くても、キーボード・タップで全部動く。

### Arduino 側がやっていること（`.ino` の C++ 部分）

1. Wi-Fi に接続して IP アドレスを取得
2. 80番ポートで Web サーバーを立てる
3. リクエストのパスで分岐：
   - `GET /state` → ジョイスティックの値を `{"x":..,"y":..,"b":..}` のJSONで返す
   - それ以外 → ゲームのHTML（`page[]`）を返す

## 3. コード解説（ブラウザ側 JavaScript）

`.ino` の `const char page[] = R"rawliteral( ... )"` の中身が、まるごと HTML+JS です。
ここを「データ → 状態 → 入力 → 更新 → 描画」の順で見ると理解しやすいです。

### 3-1. データ：ステージ定義 `stages[]`

```js
const stages=[
 { name:"Stage 1", map:[
   "#############",
   "#S #    E   #",
   ...
 ]},
 ...
];
```

- マップは **ただの文字の配列**。1文字 = 1タイル（40px四方）。
- 記号の意味：
  - `#` = 壁
  - 空白 = 床（通れる）
  - `S` = スタート地点
  - `G` = ゴール
  - `C` = コイン
  - `E` = 敵
- **迷路を変えたいときはこの文字を書き換えるだけ**。プログラム本体は触らなくていい。

### 3-2. 状態：いま何が起きているかを覚える変数

```js
let screen="select";   // 画面の状態: 選択画面 / プレイ中 / クリア
let player, goal;      // 自機とゴールの位置
let coins=[], enemies=[];   // コインと敵のリスト
let cameraX=0, cameraY=0;   // カメラ（表示範囲）の左上座標 ← 今回追加
```

- `screen` がゲーム全体の「今どのモードか」を表す中心的なスイッチ。
- `"select"`（ステージ選択）→ `"playing"`（プレイ中）→ `"clear"`（クリア）と切り替わる。

### 3-3. ステージの読み込み `loadStage(i)`

```js
function loadStage(i){
  map=stages[i].map;
  // map の文字を1つずつ見て、S/G/C/E の場所に
  // player・goal・coins・enemies の実体を作る
  ...
  screen="playing";
}
```

- **文字のマップ → 実際のゲームオブジェクト** に変換する関数。
- 例：`"S"` を見つけたら、その座標に自機を置く。`"C"` ならコインを1個追加。

### 3-4. 入力：キー・タップ・ジョイスティック

- **キーボード**：`keys["w"]=true` のように「今押されているキー」を記録。

  ```js
  if(e.key==="ArrowUp") keys["w"]=true;  // 矢印キーもWASD扱い（今回追加）
  ```

- **タップ**：クリック地点を `target`（目標地点）にして、自機をそこへ歩かせる。

  ```js
  target={x:p.x+cameraX, y:p.y+cameraY};  // カメラ分ずらしてワールド座標へ
  ```

- **ジョイスティック**：`/state` を約120msごとに取得し、傾きを移動量 `joyVX/joyVY` に変換。

  ```js
  if(j.x===0 && j.y===0) return;  // 未接続(値0)は無視（今回追加）
  ```

### 3-5. 更新 `update()`：1フレームごとの計算

```js
function update(){
  // 1. キー・ジョイの入力から移動量 dx,dy を計算して自機を動かす
  // 2. タップ目標があればそこへ歩かせる
  updateEnemies();   // 敵を動かす
  collectCoins();    // コインに触れたら回収
  checkGoal();       // 全コイン取得＆ゴール接触でクリア
  updateCamera();    // カメラを自機に追従させる（今回追加）
}
```

#### 当たり判定 `hitsWall(x,y,size)`

- 自機の四隅が壁タイル `#` に重なるかを調べる。重なるなら「壁にぶつかる」＝そこへは進めない。
- `movePlayer` は X方向・Y方向を別々に判定するので、壁に沿ってスルッと滑れる。

#### カメラ `updateCamera()`（今回の目玉）

```js
function updateCamera(){
  const mapW=map[0].length*TILE, mapH=map.length*TILE;  // マップ全体の大きさ
  const cx=player.x+player.size/2;  // 自機の中心
  cameraX=Math.max(0, Math.min(cx-200, mapW-400));
  cameraY=...;
}
```

- やりたいこと：**自機を画面中央に置きつつ、マップの端では画面がはみ出さないようにする**。
- `cx-200` … 自機を中央(400pxの半分=200)に置くためのカメラ位置。
- `Math.min(... , mapW-400)` … 右端でこれ以上スクロールしない上限。
- `Math.max(0, ...)` … 左端で0より小さくならない下限。

### 3-6. 描画 `drawPlaying()`：画面に絵を描く

```js
function drawPlaying(){
  ctx.save();
  ctx.translate(-cameraX, -cameraY);   // ★カメラ分だけ世界をずらして描く
    // 壁・コイン・ゴール・敵・自機を「ワールド座標のまま」描画
  ctx.restore();
  // HUD（タイマー等）はずらさず画面固定で表示
}
```

- ポイントは `ctx.translate(-cameraX, -cameraY)`。
  **世界全体をカメラの逆方向にずらして描く**ことで、結果的にカメラが動いて見える。
- `save()`〜`restore()` で「ずらすのはゲーム世界だけ、HUD文字は固定」を実現。

### 3-7. ゲームループ `gameLoop()`

```js
function gameLoop(){
  update();   // 計算
  draw();     // 描画
  requestAnimationFrame(gameLoop);  // 次のフレームでまた自分を呼ぶ（約60fps）
}
```

- これが心臓部。「計算 → 描画」を毎秒約60回くり返すことでゲームが動く。

## 4. 迷路を自分で編集したいとき

`stages[]` の文字を書き換えるだけです。注意点：

- **各行の文字数を全部そろえる**（ガタガタだと崩れる）
- 外周は `#`（壁）で囲む
- `S` と `G` は各1個ずつ
- **通路は2マス幅にする**（1マス幅だと敵をすり抜けられず詰む）
- `S` の近くに `E`（敵）を置かない（開幕で詰む）

> 自動生成＋クリア可能チェックは Python スクリプトで行いました。
> 大きく作り変えるときは、その「クリア可能か自動チェック」を再度回すのが安全です（依頼してもらえれば実行します）。

## 5. 用語ミニ辞典

| 用語 | かんたんな意味 |
|------|----------------|
| Canvas | ブラウザのお絵かき領域。ここにゲーム画面を描く |
| `ctx` | Canvasに描くためのペン（context） |
| ワールド座標 | マップ全体での絶対的な位置 |
| スクリーン座標 | 画面に実際に映る位置（＝ワールド座標 − カメラ位置） |
| フレーム | 1コマ。約1/60秒ごとに更新される |
| localStorage | ブラウザにデータを保存する仕組み（ベストタイム保存に使用） |
| DHCP | ルーターが機器にIPアドレスを自動で割り当てる仕組み |
