# RPG_Quest（ドラクエ風RPG）

迷路ゲームの仕組みを土台にした、**ドラクエ風のブラウザRPG**。本プロジェクトのメイン作品（開発中）。

ゲーム本体はブラウザ側の JavaScript。Arduino は HTML を配信し、ジョイスティック値を返し、効果音・LEDを鳴らす。

---

## 主な機能

### フィールド・街
- ドット絵マップを4方向に移動・カメラ追従（歩行アニメつき）
- **マップ切替**：フィールド ⇔ 街 ⇔ 東の洞窟
- **街**（魔物が出ない安全地帯）に4施設：
  - 宿屋（HP/MP全回復＋セーブ）/ 武器屋（装備購入）/ 道具屋（アイテム購入）/ 教会（復活地点設定＋回復）
- NPCと会話（1文字送りの会話ウィンドウ）

### 戦闘（ターン制コマンド）
- 草地でランダムエンカウント → 一人称視点バトル
- コマンド: たたかう / じゅもん（かえん・いやし）/ どうぐ / にげる
- ダメージ計算・敵の反撃・経験値/ゴールド・**レベルアップ**
- 敵3種（ブルン / ヤミバット / ホネナイト）

### パーティ・成長
- **仲間加入**：東の洞窟で襲われている魔法使い「マリン」を助けると仲間に
- パーティ全員が**順番にコマンド選択** → 敵が反撃。各自がレベルアップ
- 全滅すると教会（リスポーン地点）で復活

### 装備・セーブ
- 武器＝攻撃力、鎧＝守備力が戦闘に反映
- localStorage でセーブ／ロード（宿屋・教会で保存）

### 実機ハードウェア連携
- **ジョイスティック**で移動・メニュー操作
- **パッシブブザー＋ボリューム**でイベント効果音と音量調整
- **WS2812 RGBテープ**でイベント発光（攻撃=赤 / 回復=緑 / レベルアップ=金 など）

## 配線（実機で遊ぶ場合）

| 部品 | Arduino | 備考 |
|------|---------|------|
| ジョイスティック VRx / VRy / SW | A0 / A1 / D2 | VCC→5V, GND→GND |
| パッシブブザー（+） | D9 | (−)→ボリューム中央→外側→GND（直列＝音量調整） |
| WS2812 DIN | D6 | 5V→5V, GND→GND |

> ハードが無くてもキーボード・タップで全機能動作します。
> WS2812を使うため、Arduino IDE で **Adafruit NeoPixel** ライブラリの導入が必要です。

## 仕組み（HTTP通信）

ブラウザと Arduino は次の3種類の通信をします。

| パス | 向き | 内容 |
|------|------|------|
| `/`（その他） | ブラウザ ← Arduino | ゲームのHTMLを丸ごと配信 |
| `/state` | ブラウザ → Arduino | ジョイスティックの値を JSON で取得（定期ポーリング） |
| `/fx?s=...` | ブラウザ → Arduino | イベント時にブザー＋LEDを鳴らす |

## ビルド

`arduino_secrets.h.example`（リポジトリ直下）を `arduino_secrets.h` にコピーしてこのフォルダに置き、Adafruit NeoPixel を導入して Arduino IDE で書き込む。詳細はリポジトリ直下の [README](../README.md) を参照。
