# RPG_Quest（ドラクエ風ブラウザRPG）

Arduino UNO R4 WiFi を **Webサーバー**にして、PC・スマホのブラウザから遊べる **ドラクエ風RPG**。
組み込みエンジニア研修の卒業制作のメイン作品です。

ゲーム本体（描画・ロジック）はブラウザ側の JavaScript（Canvas）。Arduino は HTML/データを配信し、ジョイスティック値を返し、ブザー・LED・内蔵LEDマトリクスを制御します。

## 主な機能

### フィールド・パーティ
- ドット絵マップを4方向に移動・カメラ追従（歩行アニメつき）
- **仲間が隊列で追従**（勇者の移動履歴をたどる「足跡(trail)」方式）
- **仲間加入イベント**：東の洞窟で魔法使いマリンを救出／奥の町で旅の戦士ガルドが加入／大聖堂でシスター セラが加入（最大4人パーティ）
- NPCと会話（1文字送りの会話ウィンドウ）

### 世界・街
- 街（魔物が出ない安全地帯）に4施設：宿屋（HP/MP全回復＋セーブ）／武器屋／道具屋／教会（復活地点設定＋回復）
- テーマの違うマップ7つ：草原フィールド・はじまりの町・東の洞窟・洞窟を抜けた先の平原・奥の町（大聖堂）・魔王城への道・魔王城
- マップは `/maps.json` でデータ配信（データ駆動。マップを増やしてもプログラム本体は変えずに済む）

### 戦闘（ターン制コマンド）
- 草地・洞窟・道でランダムエンカウント → 一人称視点バトル
- コマンド：戦う／特技／呪文／道具／逃げる（職業ごとの特技・呪文）
- **弱い敵は群れで出現**（複数敵バトル）。**全体攻撃魔法・全体回復**、敵ごとの固有行動（全体攻撃・強力な一撃・自己回復）
- **属性**：弱点1.5倍／耐性0.5倍。経験値/ゴールド・レベルアップ（**5レベルごとに新しい特技・呪文を習得**）
- 場所別エンカウント表で敵を出し分け（難易度カーブ）。大量の経験値をくれる**レアモンスター「ゴールドブルン」**
- 洞窟最奥に**中ボス ゲヘナ将**（勝てない時は「引き返す」を選べる）、魔王城に**ラスボス 魔王**
- **魔王を倒すとエンディング**→ 全員全回復 → 自動セーブ → はじまりの町へ帰還
- 全滅すると教会（リスポーン地点）で復活

### 装備・セーブ
- 武器＝攻撃力、鎧＝守備力が戦闘に反映（職業別の装備制限）
- localStorage でセーブ／ロード（宿屋・教会で保存）

### 実機ハードウェア連携
- **ジョイスティック**で移動・メニュー操作
- **パッシブブザー＋ボリューム**でイベント効果音と音量調整
- **WS2812 RGBテープ**でイベント発光（攻撃=赤／回復=緑／レベルアップ=金 など）
- **本体内蔵 12×8 LEDマトリクス**を**ミニマップ**に（現在地・出入口・建物を点で表示。自機の点滅はArduino側で自走）

## 操作

| | 移動 | 決定・話す | メニュー |
|---|------|-----------|---------|
| PC | WASD / 矢印 | Space / Enter | M キー |
| スマホ | **仮想十字パッド**（画面下）／タップした地点へ移動 | **Aボタン**／NPCをタップ | **Bボタン**／右上ボタン |
| 実機 | ジョイスティック | ボタン押し込み | — |

> ハードが無くてもキーボード・タップで全機能動作します。
> スマホは**行きたい場所をタップ**するとそこまで歩いて行きます（NPCをタップすると近づいて話しかけ）。目標には金色のリングが出ます。
> **メニュー（ステータス画面）ではBGM音量を調整できます**：PC=A/D・←/→キー、実機=ジョイスティック左右、スマホ=画面内◀/▶タップ。設定はブラウザに保存され次回も引き継がれます。
> 画面左上には常時「← ゲーム選択」ボタンが表示されますが、これは統合版（GameSelect）でのみ選択画面に戻る機能を果たします。このRPG_Quest単体版では `/` がRPG自身を返すため、押すとRPGが再読み込みされます。

## 仕組み（HTTP通信）

ブラウザと Arduino は次の通信をします。**入力・出力・表示**の三系統がそろっています。

| パス | 向き | 内容 |
|------|------|------|
| `/` `/index.html` `/?...` | ブラウザ ← Arduino | ゲームのHTMLを配信（大きいので1KBずつ確実に送信。それ以外の未知パスは404で即切断） |
| `/maps.json` | ブラウザ ← Arduino | マップデータをJSONで配信（起動時に取得） |
| `/state` | ブラウザ ← Arduino | ジョイスティックの値を JSON で返す（ブラウザが定期ポーリング・**入力**） |
| `/fx?s=...` | ブラウザ → Arduino | イベント時にブザー＋RGB LED（**出力**） |
| `/led?...` | ブラウザ → Arduino | 内蔵LEDマトリクスのミニマップへ反映（**表示**） |

```mermaid
flowchart LR
    B["ブラウザ（ゲーム本体）<br/>Canvasで描画・ロジック"]
    A["Arduino UNO R4 WiFi<br/>・Webサーバー（HTML/JSON配信）<br/>・センサ入力（ジョイ）<br/>・アクチュエータ（ブザー/RGB/LEDマトリクス）"]
    B -->|"/state /fx /led（リクエスト）"| A
    A -->|"HTML / maps.json（レスポンス）"| B
```

## 配線・回路図（実機で遊ぶ場合）

<p align="center">
  <img src="回路図.png" width="600" alt="回路図：Arduino UNO R4 WiFi ＋ OLED(QR表示) / ジョイスティック / WS2812 RGB LED / パッシブブザー＋ボリューム">
</p>

> ※図はUNO表記ですが、実機は **Arduino UNO R4 WiFi**（配線は同じ）。OLEDは接続用QRの表示に使います。

| 部品 | Arduino | 備考 |
|------|---------|------|
| ジョイスティック VRx / VRy / SW | A0 / A1 / D2 | VCC→5V, GND→GND |
| パッシブブザー（+） | D9 | (−)→ボリューム中央→外側→GND（直列＝音量調整） |
| WS2812 DIN | D6 | 5V→5V, GND→GND |
| OLED（SSD1306 128×64） | SDA / SCL（I2C・0x3C） | VCC→3.3V, GND→GND（接続用QRを表示） |
| 内蔵 12×8 LEDマトリクス | （本体内蔵） | 追加配線なし |

> WS2812を使うため、Arduino IDE で **Adafruit NeoPixel** ライブラリの導入が必要です。

## 外で遊ぶ（持ち出しプレイ）

家のWi-Fiが無い屋外でも、**Arduino自身がWi-Fiアクセスポイント(AP)になる**ので単体で遊べます。電源はUSBモバイルバッテリー（5V / 1A以上推奨）をUSB-Cに挿すだけ。

> **手順・接続用QR・注意点はリポジトリ直下の [README](../README.md) に集約しています**。

## ビルド

1. （任意）家のWi-Fiで使う場合は、リポジトリ直下の `arduino_secrets.h.example` を `arduino_secrets.h` にコピーし、このフォルダ（`RPG_Quest/`）に置いて Wi-Fi（2.4GHz帯）情報を記入（**無くてもビルドできます**＝起動時にルーターが見つからなければ自動でAPモード）。
2. `RPG_Quest.ino` / `webpage.h` / `webpage_gz.h` / `maps.h` を同じフォルダに置く（クローンすれば揃っています）。
3. ライブラリ **Adafruit NeoPixel** / **Adafruit SSD1306**（依存の Adafruit GFX も一緒に入ります）/ **QRCode**（Richard Moore 作）を導入し、Arduino IDE で書き込む。
4. シリアルモニタ（9600bps）に表示される IP に `http://<IP>/`（httpsではなくhttp）でアクセス。

> ゲーム本体のソースは `webpage.h`。編集したら `_gzip_page.py`（開発用ローカルスクリプト・リポジトリ未同梱）で `webpage_gz.h` を再生成して書き込みます。

詳細はリポジトリ直下の [README](../README.md) を参照。
