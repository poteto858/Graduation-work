# 迷路ゲーム（MiniGame_Phase12_RPG）

このプロジェクトで**最初に作った迷路ゲーム**。基礎（Canvas描画・入力・状態管理・当たり判定・カメラ）を学ぶために作り、ここで得た仕組みを [RPG_Quest](../RPG_Quest/) に発展させた。

## 機能

- 迷路 3 ステージ（全ステージ「ゴール到達・全コイン取得」が可能なことを検証済み）
- ステージ選択画面
- カメラスクロール（画面より大きいマップに対応）
- コイン収集（**全部取るとゴールが開く**）／ 巡回する敵（接触でスタートに戻る）
- タイマー・ベストタイム保存（ブラウザの localStorage）
- キャラはパックマン風、敵はゴースト風、8bit風の効果音（Web Audio）

## 操作

| 操作 | 方法 |
|------|------|
| 移動 | PC: WASD / 矢印キー　スマホ: タップ　実機: ジョイスティック |
| リスタート | R キー |
| ステージ選択 | W/S・ジョイスティック上下で選び、Enter/ボタン/タップで決定 |

## 仕組み（要点）

- マップは**文字の2次元配列**。`#`=壁 / 空白=床 / `S`=スタート / `G`=ゴール / `C`=コイン / `E`=敵。
- Arduino は HTML を配信し、`/state` でジョイスティックの値を JSON で返すだけ。ゲーム本体はブラウザJS。
- 各ステージの「クリア可能か」は、自機の当たり判定を使ったピクセル空間BFSで自動検証した。
